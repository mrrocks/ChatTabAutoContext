# Changelog

## 1.5.0

- Split tab selection and unread notifications into independently disableable addon modules.
- Rename the addon suite to Chat Improvements and simplify its module names.
- Show the addon logo for the parent and both modules in the AddOns list.
- Notify only for incoming guild, group, raid, instance, whisper, and yell messages.
- Ignore public channels, say, emotes, Communities, system output, loot, and outgoing whispers.
- Preserve notification dots and whisper-glow replacement in both Blizzard chat and EllesmereUI Chat.
