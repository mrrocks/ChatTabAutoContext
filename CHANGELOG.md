# Changelog

## 1.2.0

- Added compatibility with EllesmereUI Chat 8.8 and newer.
- Preserved draft text and cursor position while cycling tabs.
- Improved secret-value safety for whisper targets, channels, and group permissions.

## 1.1.0

- Prefer the chat type or channel matching a tab's name when multiple targets are available.
- Default the Guild tab to Guild chat instead of Officer chat when both are available.
- Preserve sticky chat targets manually selected and sent for each tab until the UI reloads.

## 1.0.0

First official release.
